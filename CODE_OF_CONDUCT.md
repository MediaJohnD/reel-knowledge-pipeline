# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion about the work. To report
unacceptable behavior, open a private security advisory on this repository
(Security tab, "Report a vulnerability") and mark it as a conduct report. The
maintainer reviews every report and keeps the reporter's details confidential.
